## Featured project

### Enterprise Banking Application

A full-stack portfolio project with a React dashboard and a Spring Boot REST API backed by MySQL. The demo includes account balances, transaction history, deposits, withdrawals, transfers, and printable statements.

- [Web application and screenshots](https://github.com/PhakisoP/enterprise-banking-web)
- [Spring Boot API](https://github.com/PhakisoP/enterprise-banking-api)

The API demonstrates request validation, Flyway schema migrations, transactional money operations, and optimistic locking. This is a learning project: it does not implement login or authorization and is not a real banking service.
